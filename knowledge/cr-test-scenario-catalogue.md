# CR test-scenario catalogue — SharePoint QA Team library

One row per CR test-scenario workbook in the QA Team SharePoint library, swept on
2026-10-16. Use it to find the earlier test script for a module before you draft a
new one, and to see which rules a past CR already tested.

## How to read this

1. **Sources.** Two SharePoint folders, read in full:
   1. `Shared Documents/1. eAuto Project/eAuto - CR Test Scenarios/` — 127 workbooks.
   2. `Shared Documents/2. Secarang & CIBO Project/Enhancement CR Test Scenario/` — 13 workbooks.
2. **Local copies.** Every workbook was downloaded unchanged to
   `_reference/sharepoint/eauto-cr-test-scenarios/` or
   `_reference/sharepoint/secarang-cibo-cr-test-scenarios/`, with the SharePoint
   file name. One exception: a second copy of
   `List of Modules and Pages that requires Thumbprint (UCD & AATF).xlsx` (from the
   EAINT-9944 sub-folder) is saved as `EAINT-9944 folder - <same name>` to avoid a
   name clash. The full library listing used for the sweep is
   `_reference/sharepoint/library-listing-2026-10-16.json`.
3. **Provenance.** Each row's source is the workbook in that row (Appendix A gives
   its file and SharePoint path). In the *Key rules* column, `Sheet!Rn` is short for
   `[from SharePoint TS <this row's file>, sheet <Sheet>, row <n>]`. Full verbatim
   rules with full tags are in [business-rules-from-test-scenarios.md](business-rules-from-test-scenarios.md).
4. **Columns.**
   1. *Editor / Modified* — SharePoint "Modified By" and "Modified" date, not the author.
   2. *Sheets (rows with a TS id)* — each sheet and how many data rows carry a TS id,
      counted by a parser. It is a size guide, not an official TS count. Where a
      workbook has its own progress tracker, the key rules quote that total.
   3. *Scenario rows* — the sum of those rows.
   4. *Environment named in file* — environment names that appear anywhere in the
      workbook (for example `uat3`, `preprod1`). This records where the CR was tested
      at the time. It is **not** a rule; never reuse it as the environment for a new CR.
5. **"Catalogue only"** rows are CRs that already have a knowledge file in this repo
   (EAINT-9306, 11864, 11934, 12058, 12107, 12151, 12153, 12257, 12339). Their rules
   were not copied again; the row points to the existing file.
6. **Fees and prices are dated.** A price in a row is the price the CR tested. Later
   CRs change it (for example the STMS fee moves RM15 → RM20 → RM25). Check the newest
   CR for the module before you rely on a number.
7. Credentials, account passwords and personal test data found in some workbooks
   (Configuration sheets, CIBO role sheets, RHB statement sample) are deliberately
   not reproduced here.
