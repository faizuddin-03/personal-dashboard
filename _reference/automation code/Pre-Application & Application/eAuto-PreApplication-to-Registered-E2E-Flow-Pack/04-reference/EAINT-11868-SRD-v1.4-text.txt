2.0 REQUIREMENT
2.1 High-Level Requirement Overview
# Item Description
2.1.1 Enhancement Overview Implement three enhancements to the eAuto Application flow for potential
UCDs: automated reminder emails, a one-time application expiry
extension, and application link reactivation.
2.1.2 Key Value(s) Expected Reduce onboarding drop-off by proactively reminding UCDs of pending
actions, give assignees flexibility to extend an application once, and allow
expired application links to be reactivated after payment.
2.1.3 Additional Note(s) Ops team to provide 5 email templates in total: 6 reminder scenarios.

2.2.2 Existing Issue & Expected Behaviour
# Item Description
1 Existing Issue / Behaviour There are currently no automated reminders sent to potential UCDs, no mechanism
for an assignee to extend an application before it expires, and expired application
links cannot be reactivated.
2 Expected New Handling / The system sends automated reminder emails at defined triggers, allows the
Behaviour assignee to extend an application once, and allows expired application links to be
reactivated via email after payment (valid for 90 days from payment date).
