2.0 REQUIREMENT
2.1 High-Level Requirement Overview
# Item Description
2.1.1 Enhancement Overview Allow a BackOffice user to extend the expiration of a potential UCD
application once for 30 days, with remarks recorded against the
application.
2.1.2 Key Value(s) Expected Give BackOffice users the flexibility to keep a near-expiry or recently
expired application active without a reactivation payment, so that fewer
applications lapse before completion.
2.1.3 Additional Note(s) The Application Expiry Extension scope was separated from EAINT-
11868, which now covers reminder emails and application link
reactivation only.

2.2.2 Existing Issue & Expected Behaviour
# Item Description
1 Existing Issue / Behaviour There is currently no mechanism for a BackOffice user to extend an application
before or shortly after it expires. Once an application expires, it can only be revived
through application link reactivation.
2 Expected New Handling / The system shall allow a BackOffice user to extend an application once for 30 days.
Behaviour
The Extend button shall be available from 30 days before the expiry date until 3
months after the expiry date.
Extension remarks shall be recorded and the updated expiry date shall be reflected
in the Application Listing.
