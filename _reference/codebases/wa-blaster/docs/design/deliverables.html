Export notes

Static spec pages (tokens.html, components.html, this index) can be exported to PNG via browser screenshot (Cmd+Shift+S) or saved as PDF via Cmd+P → Save as PDF.

Prototype routes are fully responsive — open at 1440 / 1024 / 375 in browser dev tools to capture each viewport. Every screen has a stable ?r= URL.

Figma-compatible specs: all design tokens are sourced from styles.css as CSS custom properties — engineering can ingest them directly or use the same hex values to populate Figma styles.
