[2026-07-14 17:58] Charmain Ea Chiang: ok noted ya, Everyone just to make sure we are all aligned on the transaction status behaviour: Tx Status = - : As long as no appointment has been made, Payment = OK. Tx Status = Pending: Transaction remains Pending if there is at least one appointment that is not in a final status (Completed/Cancelled/Expired). A Failed appointment is also treated as non-final as it will proceed to the reappointment flow. BDP without installation will show Pending after Payment = OK. Tx Status = Cancelled: Transaction becomes Cancelled only when all appointments are Cancelled. Payment = Failed. Tx Status = Completed: The transaction becomes Completed only when all appointments are in a final status (Completed/Cancelled/Expired) and there is at least one appointment with Completed status. Tx Status = Failed: The only scenario that currently results in a Failed appointment status is when UCD attempts to reschedule an appointment on the same date as the existing scheduled appointment. Tx Status = Expired: Transaction becomes Expired only when all appointments are Expired. Installation will auto expired after 2 months if no appointment made after the payment.
