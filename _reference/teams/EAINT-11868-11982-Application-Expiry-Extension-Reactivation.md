[2026-08-20 18:33] Yi Link Lim: Siti Nur Azila Binti Mohamed Just to share that here is the summary of discussion between me and Lim Xiwei on the small details in PA & A (some of them are not included in SRD) ... Item 1 - Email Reminder: When a form is reactivated, the system automatically sends a reminder email. For the 2-month and 1-month reminders: a. Each reminder is triggered only on the exact scheduled date. b. Each reminder is sent only once. c. The reminder cycle resets whenever the application is extended or reactivated. Item 2 - Expiry Extension: The application status returns to Approved when the application is extended. The Extend button is no longer displayed once the 3-month extension window has passed. Concurrent Extend clicks (lower priority): a. If two users (or two tabs) click Extend on the same application at the same time, one click succeeds and the other fails. b. The failed click shows the error "Action could not be completed because some details have changed. Please refresh and try again." c. The application is extended once, not twice. Item 3 - Reactivation: The application status returns to Approved when the application is reactivated. For the [Reactivate] button in the expiry email: a. On the 1st click, the UCD pays the PA fee. b. On the 2nd click, the UCD is redirected to the application form (now reactivated). An SSM refresh is only triggered before Step 4. a. At Step 2, director IC files are matched to each director's name. b. If a director is removed, their existing IC file is removed along with them. c. A newly added director has no ID file by default. d. The director count is overwritten based on the latest SSM data. e. For the e-Invoice PIC, the "Same as Director/Business Owner in Charge" selection is not stored. f. It is cleared through name matching only when the e-Invoice contact name matches the previous Director-in-Charge and that director has changed. g. Editability of the SSM-changed fields depends on the application status. i. On a Reverted form during reactivation, the SSM-changed fields (Director, e-Invoice, etc.) are added to the reverted-fields set so the UCD can edit them. ii. On a Submitted-for-Approval form, the UCD still cannot edit these fields. iii. BO handles any empty required fields on the Submitted-for-Approval form. iv. When BO clicks Submit for Approval, an error popup titled "Unable to proceed" appears with the message "Submission failed. Please try again." v. After BO clicks OK, the system displays "This field is required." on each blank required field. For a failed-payment reactivation: a. The resulting PA record does not appear in the PA listing. b. The onboarding link remains available on the latest expired PA record.
