2.0 REQUIREMENT

2.1 High-Level Requirement Overview

#      Item                   Description

2.1.1  Enhancement Overview   Enhance the Payment Mode column in the Transaction Listing
                              and the Payment Report to display the payment gateway,
                              payment method and payment details in 1 standard format.

2.1.2  Key Value(s) Expected  Allow the requestor to identify the payment gateway and
                              payment method used for each transaction.

                              Allow the requestor to analyse which group of users the
                              payment under Secarang comes from.

2.1.3  Additional Note(s)     Refer to source ticket ESI-355.

2.2.2 Existing Issue & Expected Behaviour

#  Item  Description

1  Existing Issue / Behaviour The Payment Mode column is not available in CIBO > Transaction

         Management > Transaction Listing and in the exported file of Transaction

         Listing.

         The Payment Mode column is available in CIBO > Payment Report and in
         the exported file of Payment Report. The display value shows the
         payment gateway name only, which is either BoldPay or Fiuu.

                            All 4 affected pages display the Payment Mode value in the following
                            format:

                            2. BoldPay | Online Banking ­ FPX-Bank Name
