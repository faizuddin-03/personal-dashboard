Overview

Adds two e-wallet payment methods — GrabPay and ShopeePay — to the Secarang gateway (Fiuu). Each wallet also offers a Buy-Now-Pay-Later option once the customer is inside the wallet's own app: pay in full now, next month, or in instalments. CIBO's Payment Management gets matching filters and columns so these transactions are visible and reportable.

Where the changes land

Secarang checkout Two new payment options at checkout: GrabPay, ShopeePay
Backend Reuses the existing card-payment data block + 1 new column, keyed off Fiuu's grabpay_indicator field (GPWALLET / POSTPAID / INSTALMENT_4)
CIBO · Payment Channels filter REQ-011–013 New "Fiuu - eWallet" filter option; ticking it defaults all 4 sub-options on — GrabPay, GrabPay - PayLater by Grab, ShopeePay, ShopeePay - SPayLater — and each can be individually unticked
CIBO · Transaction Management Payment method column fixed — no longer shows "–" (done, confirmed 08/09)

Payment Reference ID

New in SRD v1.1 — REQ-014, REQ-015

Every e-wallet transaction gets an EW identifier in its Payment Reference ID, e.g. LON20260908SEW0002. The updated ID must show up in five places: Payment Management Listing, its exported file, Transaction Details (inside Transaction Management), Payment Report, and its exported file — CIBO Payment Report is a newly affected page, not previously called out in the ticket description.
