01

Overview

Lonpac flagged 5 urgent live issues on the Secarang website: wrong insurer name ("Lonpac Insurance Berhad" instead of "Lonpac Insurance Bhd") on the About Us, FAQ, Support and Confirmation pages, plus an outdated SDPA Policy Wording link on the Add-on page. These 5 fixes (REQ-001 to REQ-005) are already deployed to production, 11 August 2026.

In parallel, the eAuto insurance module was reviewed for the same naming issue. Most eAuto screens already show the correct name and need no change. Version 1.1 of the SRD (23 September 2026) added 4 new requirements to standardise the name in the Insurance Company filter dropdown and result table, on both UCD and BackOffice, which still showed the longer "Lonpac Insurance Berhad" through a shared plan-code label.

08

Navigation — how to reach each page

Sourced from a code-reading chatbot with access to eauto, prod, origin/prod/master, 25 September 2026. Navigation only, not yet verified against a live UI. Recorded in full in knowledge/flow-eauto-insurance-enquiry.md.

  1. BackOffice Insurance Transaction Listing (REQ-012, REQ-013): BackOffice → Insurance menu → Insurance Transaction Listing. Filter dropdown in the top search panel; result table has an Insurance Company column. Click a row for its Policy Detail view.
  2. UCD Transaction Listing (REQ-014, REQ-015): dealer/UCD portal → Motor Insurance → Transaction Listing tile. Filter dropdown appears in both the basic and advanced filter areas — check both.
  3. UCD Report (REQ-014, REQ-015): dealer/UCD portal → Motor Insurance → Report tile. Same two-places-on-the-page filter pattern as Transaction Listing.
  4. Insurance Dashboard portal — a separate login, not reachable from BackOffice's regular menu: /motorInsurance/login/, insurance-user account. From the dashboard home: Payment Report (Pemaju) — the hidden-blast-radius page — and the Insurance Company / Agency Performance chart on the home page itself.
  5. eSTM Transaction Detail: BackOffice → /view/estm/enquiry → click into a transaction row.
  6. Credit Portal Insurance Enquiry: not a menu item — open a Hire Purchase record with an insurance component, then its Insurance Enquiry tab.
