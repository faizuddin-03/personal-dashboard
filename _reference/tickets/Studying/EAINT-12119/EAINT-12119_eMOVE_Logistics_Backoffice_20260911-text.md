Hub Management

Maintain the logistics hub records. An address is checked against Google Maps, then confirmed by Operations before the hub can be used. Distance is measured between hub coordinates, so the pin must sit on the right place. Sabah, Sarawak and Labuan hubs may be recorded here; the restriction applies on the UCD portal only.

[button] Add New Hub

Google Match — what each value means

How precisely Google placed the address. Distance is measured between hub coordinates, so an imprecise pin gives the wrong distance, the wrong tier and the wrong price.

| Value | What it means | Typical error | Can the hub be used |

| Exact address | Matched the building at that street number | Within metres | Yes |

| Street level | Matched the street but not the exact premises | 100 to 200 metres | Yes |

| Neighbourhood | Matched only an estate or area. Google returns the centre point of that area | Up to about 2 km | No, Operations must confirm or set the pin |

| Different place | Matched a location that is not the one recorded | 10 km or more | No, the address is likely wrong |

| Set by Operations | Coordinates entered by hand after review, replacing what Google returned | Not applicable | Yes |
